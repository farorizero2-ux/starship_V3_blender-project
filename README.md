# Starship V3 Super Heavy Booster - 3D Modeling Project

## 🚀 About the Project
This project is an accurate 3D model and structural breakdown of the SpaceX Starship V3 Super Heavy first-stage booster, created using Blender. The goal of the project is to study aerospace engineering proportions, propulsion systems (Raptor engine layout), and aerodynamic control elements (Grid Fins).

## 📊 Key Specifications
* Vehicle: Starship V3 (Super Heavy Booster)
* Software Used: Blender
* Key Components Modeled:
  * Stainless steel cylindrical sections & weld rings
  * Hot-staging ring (interstage)
  * Grid fins (aerodynamic control surfaces)
  * Engine bay layout (central cluster and outer ring of Raptor engines)
